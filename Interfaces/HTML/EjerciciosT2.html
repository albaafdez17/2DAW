Definiciones

HTML
Lenguaje utilizado para crear la estructura de una página web.
CSS
Lenguaje utilizado para definir el aspecto y diseño de una página web.
JavaScript
Lenguaje de programación utilizado para añadir interactividad a una página web.
DOM
Modelo que representa la estructura de un documento HTML.
